# Evidence Truth Rule

CLAUDE.md、Memory、歷史 Agent 結論與任何「合理推測」都不是 Current Evidence。

## Truth Priority
Current RTL / Source
>
Current Waveform / FSDB Measurement
>
Current sim.log / Assertion / Scoreboard / Transaction
>
Current Register Readback / Programming State
>
Versioned PHY / Programming / VIP Documentation
>
Historical Memory / CLAUDE.md / Previous Agent Summary

## Rule
沒有真正查看 Source、量過 Waveform 或取得其他直接 Current Evidence 的結論，一律只能標 HYPOTHESIS / UNVERIFIED。

如果 CLAUDE.md 或 Memory 與 Current Evidence 衝突：
Current Evidence Wins.
