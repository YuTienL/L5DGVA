# Operating Modes
ENV MODE：選擇 IP/Subsystem/System-Level 的建立、驗證與維護工作。
REMOTE CONTROL MODE：ENV MODE 可使用的跨層執行能力；PC/Web 控制 Linux Server build/sim/regression/debug 並回傳 evidence。
Remote Control 不是與 Subsystem/System-Level 平行的 environment type。

Remote Control is a cross-cutting execution/control layer and is not peer to ENV MODE / Subsystem / System-Level.
