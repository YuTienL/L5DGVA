4.2 Error Handling and Recovery

A CRC error requires a soft reset before normal operation can recover.

On a timeout error, the DMA engine automatically retries the transfer up to 3 times.

Parity errors are recoverable only if software issues a manual re-initialize sequence.

The single-bit ECC error condition automatically recovers via an internal retry within 2 cycles.
