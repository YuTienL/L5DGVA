Interrupt Controller

This device asserts interrupts on IRQ0..IRQ3. Priority order: IRQ0 > IRQ1 > IRQ2 > IRQ3.
IRQ0 has the highest priority among all sources.

Each interrupt can be masked via the INTR_MASK register; setting a bit disables the
corresponding interrupt from reaching the CPU.

The DMA controller supports 4 independent DMA channels, each with its own descriptor ring.
