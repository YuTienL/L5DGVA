Chapter 4: Performance Characteristics

This DMA engine computes throughput as the number of bytes transferred divided by the number of elapsed cycles.

Bandwidth is calculated as the product of the data width and the clock frequency, divided by eight.

Latency is defined as the number of cycles from request issue to first response beat.

The engine's throughput is a key design consideration for high-speed transfers.
